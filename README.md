Script otomatis untuk memindahkan data dari file Excel di Dropbox ke Google Spreadsheet.

| | Log - Monitoring | Log Monitoring | Sheet1 |
| | KTH | KTH | Sheet1, Sheet2 |
| Potential-Farmer-for-ARR | Follow Up Petani | Database Planting 2 | FOLLOW_UP_PETANI |
| CT-Compile | CT Compile | cameratrap db | db-CT Compile |
| BT-Compile | BT | BT | db-BT |
